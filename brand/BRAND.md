# ContentCore brand

## Name

**ContentCore**: one word, with a capital C at the start of both halves. Packages are written in code style: `@contentcore/react`, `@contentcore/core`.

## Mark

![ContentCore logo](logo-128.png)

A "C" built from three content blocks around an amber core. The blocks stand for the page's blocks, and the core for the shared engine that renders them.

| File | Use |
|---|---|
| [`logo.svg`](logo.svg) | Source of truth: READMEs on GitHub, docs, sites |
| [`logo-512.png`](logo-512.png) | npm READMEs, social cards, app icons |
| [`logo-128.png`](logo-128.png) | Small raster uses |
| [`social-preview.png`](social-preview.png) | GitHub repo card (1280×640) |

**Rules:**
- Keep the tile, and don't recolour the core.
- Leave clear space of at least ¼ of the logo's width around it.
- The mark works down to 16 px.
- Never stretch it, rotate it, or put it on a busy photo.

## Colours

| Role | Hex | |
|---|---|---|
| Primary (Indigo) | `#4f46e5` | Links, buttons, the repo-card accent band |
| Tile gradient | `#7b78ff` → `#4338ca` | Logo tile only |
| Core (Amber) | `#fde68a` → `#f59e0b` | Logo core. As a UI highlight, use `#f59e0b` sparingly |
| Ink | `#0f172a` | Text on light |
| Paper | `#ffffff` | Text on the tile, light backgrounds |

**Social card:** dark theme, accent `#7b78ff` (the lighter indigo reads better on dark).

## Voice

Plain and specific: say what it does and what it guarantees ("cached by default", "renders every HTML element safely"), with no hype. Product name first, then what it is: "ContentCore: schema-driven content for React".
